# 사업계획서(PSST) 매핑

작성일 2026-11-11. BM-Core 산출물(캔버스·7단계·bm-calc 결과)을 사업계획서의 PSST(문제인식 Problem · 실현가능성 Solution · 성장전략 Scale-up · 팀 구성 Team) 항목에 옮기는 대응표다. 7단계·증거 등급 정본: [BM_METHOD](../method/BM_METHOD.md). 블록 정의: [BMC_TEMPLATE](../canvas/BMC_TEMPLATE.md). 계산: [08_CALCULATION_ENGINE](../../CALCULATION_ENGINE.md).

## 1. 양식 차이 안내

| 항목 | 상태 |
|---|---|
| 지원사업별 양식 | 공고·연도마다 목차, 분량, 필수 항목, 배점이 다르다. 예: 예비창업패키지, 초기창업패키지. 각 양식의 세부 구성은 단정하지 않는다 |
| 하위 항목 이름·순서 | 공고별 확인 필요(미확인). 아래 표는 일반적인 PSST 구조를 가정한 제안 매핑이다 |
| 사용법 | 실제 공고의 양식을 받아 아래 "공고 양식 항목" 칸에 옮겨 적고, 대응 열을 그대로 재사용한다 |
| 절차 | 공고문·양식 원문 확인 -> 항목 대응 -> E 등급 문장 점검(3장) -> 제출 전 수치 출처 점검 |

## 3. 증거 등급별 인용 규칙

등급 정의는 BM_METHOD 4.2. 사업계획서 본문에 쓸 때의 규칙(제안)이다.

| 등급 | 본문 표현 | 규칙 |
|---|---|---|
| A 실결제·계약·사용 로그 | "실적"으로 쓸 수 있다 | 표본 수·기간·측정 방법을 함께 적는다. 통계적 타당성을 자동 보장하지 않는다 |
| B 사전예약·행동 | "사전 수요 확인"으로 쓴다 | 전환율의 분모(방문 수)와 기간을 적는다. 실결제로 표현하지 않는다 |
| C 인터뷰·설문 | "고객 인터뷰 결과"로 쓴다 | 인원·선정 방식·일자를 적는다. 일반화하지 않는다 |
| D 경쟁사·시장 조사 | "공개 자료 기준"으로 쓴다 | 출처·조회일을 적는다. 오래된 자료는 연도를 표기한다 |
| E AI 추정·창업자 가정 | "가정"으로만 쓴다 | 사실·실적·시장 규모처럼 쓰지 않는다. "가정"이라 밝히고 검증 계획(6단계)과 함께 제시한다 |

| 점검 | 내용 |
|---|---|
| 출처 없는 수치 | 근거가 없으면 문장에서 빼거나 `미확인`으로 두고 근거를 확보한 뒤 쓴다 |
| 시장 규모·성장률 | AI가 만든 수치는 E. 공신력 있는 자료(D)로 확인되기 전에는 단정 문장 금지 |
| 계산 수치 | bm-calc 결과는 입력값의 등급을 따른다. 입력이 E이면 결과도 "가정에 기반한 추정"으로 쓴다 |
| 제출 전 | 본문 수치마다 등급·출처 표를 만들어 대조한다(E 항목은 "가정" 표기 확인) |

## 4. BookForge 예시 적용 (제안)

BookForge 수치는 모두 가정치(E)다([BM_METHOD](../method/BM_METHOD.md) 3장).

| PSST 항목 | 쓸 내용(제안) | 본문 표현 |
|---|---|---|
| 문제인식: 문제의 크기 | 전자책 한 권에 수십만 원, 수 주 소요(외주·도구 분산) | "가정"이며 인터뷰 20명 결과로 교체 예정 |
| 실현가능성: 수익 모델 | Pro 월 29,000원, 공헌이익률 70% | "가정 기반 추정" |
| 성장전략: 손익분기 | 월 고정비 300만원 기준 약 148명(기준 시나리오) | "가정 기반 추정", 보수 223명·낙관 114명 병기 |
| 실현가능성: 검증 | 사전예약 전환 5%, 첫 결제 5건 목표 | 목표치이며 실적 아님. 달성 후 A·B 등급으로 서술 |
